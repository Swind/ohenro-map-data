# 一日一斉おもてなし遍路道ウォーク資料來源

```bash
python3 -m omotenashi_henro_inspection
```

此命令下載並以 SHA-256 保存 immutable KML snapshot 至
`source/omotenashi-henro-inspection/snapshots/<sha256>/route1102.kml`；
`current.json` 指向目前快照。來源頁為
<https://www.omotenashi88.net/issei/issei-map>，KML 為
<https://komelabo.sakura.ne.jp/omotenashi-henro-walk/kml/route1102.kml>。

資料語義是「一日一斉おもてなし遍路道ウォーク」遍路道點檢活動的覆蓋路線，可作為較可能受該活動關注的路段參考。這不代表道路目前已維護、可通行或適合導航。發布者也說明路線會隨時代變遷、幾何可能與實際道路偏移，且必須以現場狀況與交通管制為準。
